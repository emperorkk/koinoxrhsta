## §2.4α Κανόνας ιδιοκτήτη/ενοικιαστή ανά κατηγορία δαπάνης (Δ5 — αναλυτικά)

Κάθε **κατηγορία δαπάνης** φέρει:

| Πεδίο | Τιμές | Νόημα |
|---|---|---|
| `owner_pct` | 0–100 | Ποιο ποσοστό της δαπάνης βαρύνει τον **ιδιοκτήτη** (το υπόλοιπο τον ενοικιαστή) |
| `owner_share_basis` | `PRORATA` \| `LUMP_SUM` | Πώς υπολογίζεται η συμμετοχή του ιδιοκτήτη |
| `owner_lump_amount` | ποσό | Μόνο όταν `LUMP_SUM`: **κατ' αποκοπή** ποσό ανά ιδιοκτησία |
| `vacant_behavior` | `OWNER_PAYS_ALL` (default) \| `COEFFICIENT(x)` \| `EXEMPT` | Τι γίνεται όταν δεν υπάρχει ενεργός ενοικιαστής |

**Αλγόριθμος ανά διαμέρισμα και δαπάνη:**

```
1) unit_amount = κατανομή της δαπάνης στο διαμέρισμα (χιλιοστά/ισομερώς/κατανάλωση/…)

2) Διαχωρισμός:
   αν owner_share_basis = PRORATA:
        owner_amount  = unit_amount × owner_pct/100        ← «μερίζεται στα χιλιοστά»
        tenant_amount = unit_amount − owner_amount
   αν owner_share_basis = LUMP_SUM:
        owner_amount  = owner_lump_amount                  ← «κατ' αποκοπή συμμετοχή»
        tenant_amount = unit_amount − owner_amount   (≥ 0· τυχόν πλεόνασμα
                        ανακατανέμεται στους υπόλοιπους κατά χιλιοστά)

3) Κενό/κλειστό (δεν υπάρχει ενεργός ενοικιαστής στην περίοδο):
   OWNER_PAYS_ALL → owner_amount += tenant_amount ; tenant_amount = 0
   COEFFICIENT(x) → χρεώνεται x% του tenant_amount στον ιδιοκτήτη,
                    το υπόλοιπο ανακατανέμεται στα υπόλοιπα διαμερίσματα κατά χιλιοστά
   EXEMPT         → tenant_amount = 0 και ανακατανέμεται εξ ολοκλήρου
```

**Προεπιλογές κατηγοριών** (παραμετρικές ανά κτίριο):

| Κατηγορία | `owner_pct` | `basis` | Κενό διαμέρισμα |
|---|---|---|---|
| ΔΕΗ κοινοχρήστων, Ύδρευση, Καθαριότητα, ΔΕΗ & συντήρηση ανελκυστήρα, Κηπουρός | 0 | PRORATA | OWNER_PAYS_ALL |
| Θέρμανση — πάγιο | 0 | PRORATA | OWNER_PAYS_ALL |
| Θέρμανση — μεταβλητό (ώρες) | 0 | PRORATA | EXEMPT (δεν υπάρχει κατανάλωση) |
| Επισκευές/αντικαταστάσεις, Βαψίματα | 100 | PRORATA | — |
| Ασφάλιστρα κτιρίου, Νομικά/Τεχνικά | 100 | PRORATA | — |
| Εισφορά αποθεματικού | 100 | PRORATA ή LUMP_SUM | — |
| Αμοιβή διαχείρισης | 0 ή 100 (ρύθμιση) | PRORATA | OWNER_PAYS_ALL |

Κάθε **δαπάνη** μπορεί να κάνει **override** τα παραπάνω (π.χ. μια συγκεκριμένη επισκευή που με απόφαση ΓΣ μοιράζεται 50/50). Το override καταγράφεται στο audit log και τυπώνεται στην ανάλυση του ειδοποιητηρίου.
