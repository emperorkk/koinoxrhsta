# 5. Προδιαγραφή εντύπου «Συγκεντρωτική Κατάσταση Κοινοχρήστων»

Βάση: υπόδειγμα **Apical Service** (ΚΩΔΙΚΟΣ 000335, ΑΓΙΟΥ ΝΙΚΟΛΑΟΥ 3 ΜΑΡΟΥΣΙ, περίοδος **ΑΠΡ-ΜΑΙΟΣ-ΙΟΥΝ 2026**, έκδοση 2/7/2026, γενικό σύνολο 1.057,51 €). Το έντυπο αναπαράγεται **όπως είναι**.

## 5.1 Δομή (3 ζώνες)

```
┌── ΖΩΝΗ Α: ταυτότητα ────────┬── ΖΩΝΗ Β: ομάδες δαπανών (blocks) ─────────────────────┐
│ Λογότυπο/στοιχεία γραφείου  │ ΚΟΙΝΟΧΡΗΣΤΑ │ ΘΕΡΜΑΝΣΗ │ ΑΣΑΝΣΕΡ                       │
│ ΚΩΔΙΚΟΣ | ΗΜ/ΝΙΑ ΕΚΔΟΣΗΣ    │             │ ΑΥΤΟΝΟΜΙΑ│ ΑΥΤΟΤΕΛΕΙΣ ΧΡΕΩΣΕΙΣ ΙΔΙΟΚΤΗΤΩΝ│
│ ΜΗΝΑΣ (από–έως)             │             │ BOILER   │ ΔΑΠΑΝΕΣ ΣΕ ΙΣΑ ΜΕΡΗ           │
│ ΔΙΑΧΕΙΡΙΣΤΗΣ / ΔΙΕΥΘΥΝΣΗ    │             │ ΕΙΔΙΚΕΣ  │ ΓΕΝΙΚΟ ΣΥΝΟΛΟ                 │
│ ΠΕΡΙΟΧΗ | ΑΝΑΚΟΙΝΩΣΗ (κάθετο)│            │ ΕΚΔΟΣΗ ΛΟΓΑΡΙΑΣΜΩΝ                       │
├── ΖΩΝΗ Γ: πίνακας επιμερισμού ανά διαμέρισμα ─────────────────────────────────────────┤
│ Α/Α │ ΟΝΟΜΑΤΕΠΩΝΥΜΟ │ ΑΡ.ΔΙΑΜ │ ΧΙΛΙΟΣΤΑ (3) │ ΩΡΕΣ (2) │ ΠΟΣΟ ΑΝΑΛΟΓΙΑΣ (12) │ ΓΕΝΙΚΟ │
└───────────────────────────────────────────────────────────────────────────────────────┘
```

## 5.2 Ομάδες δαπανών → στήλες (η βασική αντιστοίχιση)

Κάθε **block** της ζώνης Β αντιστοιχεί σε **μία στήλη** της ζώνης Γ. Αυτή είναι η κεντρική οντότητα του μοντέλου — την ονομάζω **ομάδα δαπανών (`cost_group`)**:

| Block εντύπου | Στήλη πίνακα | Πίνακας κατανομής | Μέθοδος |
|---|---|---|---|
| ΚΟΙΝΟΧΡΗΣΤΑ | ΚΟΙΝ/ΣΤΑ | Κοινοχρήστων | χιλιοστά |
| ΘΕΡΜΑΝΣΗ → ΠΕΤΡΕΛΑΙΟ | ΘΕΡΜΑΝΣΗ | Θέρμανσης | χιλιοστά (πάγιο) |
| ΑΥΤΟΝΟΜΙΑ | ΑΤΟΜΙΚΗ | — | **ώρες** ωρομέτρησης |
| BOILER | BOILER | — | **ώρες** boiler |
| (κλειστά/μειωμένη συμμετοχή) | ΚΛΕΙΣΤΑ | Θέρμανσης | συντελεστής επί του παγίου |
| ΑΣΑΝΣΕΡ | ΑΣΑΝΣΕΡ | Ανελκυστήρα | χιλιοστά |
| ΕΙΔΙΚΕΣ ΔΑΠΑΝΕΣ | ΕΙΔΙΚΕΣ | Κοινοχρήστων | χιλιοστά |
| ΕΚΔΟΣΗ ΛΟΓΑΡΙΑΣΜΩΝ | ΕΚΔΟΣΗ | Κοινοχρήστων ή ισομερώς | ρύθμιση |
| ΑΥΤΟΤΕΛΕΙΣ ΧΡΕΩΣΕΙΣ ΙΔΙΟΚΤΗΤΩΝ | ΙΔΙΟΚΤΗΤΩΝ | Κοινοχρήστων | χιλιοστά — **βαρύνει ιδιοκτήτη** |
| (ατομικές χρεώσεις) | ΑΥΤΟΤΕΛΗ | — | **καρφωτό ποσό** ανά διαμέρισμα |
| ΔΑΠΑΝΕΣ ΣΕ ΙΣΑ ΜΕΡΗ | ΙΣΑ ΜΕΡΗ | — | ισομερώς |
| (διαφορά στρογγυλοποίησης) | ΣΤΡΟΓΓ | — | βλ. §5.4 |

Οι ομάδες είναι **παραμετρικές ανά κτίριο**: προστίθενται/αφαιρούνται και οι στήλες του εντύπου ακολουθούν. Κενή ομάδα → η στήλη τυπώνεται κενή (όπως εδώ οι ΘΕΡΜΑΝΣΗ/ΑΤΟΜΙΚΗ/BOILER/ΙΣΑ ΜΕΡΗ).

## 5.3 Γραμμές δαπανών

- Ελεύθερη περιγραφή + ποσό, με **πολλαπλές γραμμές ανά ομάδα και ανά μήνα** της περιόδου: «ΔΕΗ ΜΑΙΟΥ 167,00», «ΣΥΝΕΡΓΕΙΟ ΚΑΘ/ΣΜΟΥ ΑΠΡΙΛΙΟΥ 60,00 / ΜΑΙΟΥ 42,50 / ΙΟΥΝΙΟΥ 85,00».
- Υποστήριξη **ποσότητα × τιμή** στην περιγραφή: «ΣΥΝΤΗΡΗΣΗ 51,76*3 → 155,28».
- Κάθε block κλείνει με **ΣΥΝΟΛΟ**· το άθροισμα όλων = **ΓΕΝΙΚΟ ΣΥΝΟΛΟ**.

## 5.4 Κανόνας στρογγυλοποίησης — εύρημα από το υπόδειγμα

Στο υπόδειγμα, το άθροισμα της στήλης ΓΕΝΙΚΟ ΣΥΝΟΛΟ των 11 διαμερισμάτων δίνει **1.057,50 €** ενώ το ΓΕΝΙΚΟ ΣΥΝΟΛΟ των δαπανών είναι **1.057,51 €** — **διαφορά 1 λεπτού**. Αντίστοιχα, τα κελιά της στήλης ΚΟΙΝ/ΣΤΑ αθροίζουν 492,26 € ενώ το ΣΥΝΟΛΟ τυπώνεται 492,23 €. Οφείλεται σε δύο ασυνέπειες: τα κελιά στρογγυλοποιούνται, ενώ τα σύνολα γραμμής υπολογίζονται από αστρογγύλευτες τιμές.

**Κανόνας που υιοθετούμε:**
1. Κάθε κελί στρογγυλοποιείται κανονικά (half-up, 2 δεκαδικά) → **ίδια χιλιοστά ⇒ ίδιο ποσό**, πάντα.
2. Το σύνολο γραμμής = **άθροισμα των τυπωμένων κελιών** (όχι των αστρογγύλευτων).
3. Η υπολειπόμενη διαφορά κάθε στήλης καταχωρείται στη στήλη **ΣΤΡΟΓΓ** ενός διαμερίσματος (ρύθμιση: *μεγαλύτερα χιλιοστά* — default, *διαμέρισμα διαχειριστή*, ή *εκ περιτροπής ανά έκδοση*).
4. Αποτέλεσμα: **Σ(κελιών) = ΣΥΝΟΛΟ** και **Σ(γενικών συνόλων) = ΓΕΝΙΚΟ ΣΥΝΟΛΟ**, ακριβώς, πάντα.

Εναλλακτική ρύθμιση: *largest remainder* (χωρίς στήλη ΣΤΡΟΓΓ, αλλά με ±1 λεπτό διαφορά μεταξύ διαμερισμάτων ίδιων χιλιοστών).

## 5.6 Τι κρατάμε επιπλέον από το υπόδειγμα

- **ΚΩΔΙΚΟΣ κτιρίου** (000335) + ημερομηνία έκδοσης στην κεφαλίδα.
- **ΜΗΝΑΣ** ως ελεύθερο κείμενο περιόδου («ΑΠΡ-ΜΑΙΟΣ-ΙΟΥΝ 2026») — παράγεται αυτόματα από το από–έως, με δυνατότητα override.
- Πλαίσιο **ΑΝΑΚΟΙΝΩΣΗ** (κάθετος τίτλος) — ελεύθερο κείμενο ανά έκδοση.
- Γραμμή **κατάστασης αποθεματικού** στο block ιδιοκτητών: «ΑΠΟΘΕΜΑΤΙΚΟ ΜΕΧΡΙ ΚΑΙ 31/6/2026: 777,21 − 719,20 (ΜΕΤΑΤΡΟΠΗ ΛΕΒΗΤΑ) + 400 = 458,01» → παράγεται **αυτόματα** από τις κινήσεις του αποθεματικού (υπόλοιπο → αναλήψεις με αιτιολογία → νέα εισφορά → νέο υπόλοιπο).
- Ίδιο πρόσωπο σε **πολλά διαμερίσματα** (Δ2 + ΔΩΜ) — υποστηρίζεται από το μοντέλο.
- Χρωματικός κώδικας: κίτρινο = στήλη ΠΟΣΟ, γαλάζιο = ΣΥΝΟΛΑ, έντονο πλαίσιο = ΓΕΝΙΚΟ ΣΥΝΟΛΟ.
