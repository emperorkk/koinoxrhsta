# Κοινόχρηστα

Εφαρμογή έκδοσης και διαχείρισης κοινοχρήστων πολυκατοικιών:
πολυκατοικίες → διαμερίσματα → χρήστες (login με email) → ιδιότητες (ιδιοκτήτης / ενοικιαστής / διαχειριστής)
→ δαπάνες & πίνακες χιλιοστών → έκδοση περιόδου (από–έως μήνες) → συγκεντρωτική κατάσταση & ειδοποιητήρια
→ εισπράξεις → αποθεματικό με +/− κινήσεις.
